# FileOrganizer

Десктоп-приложение для Windows 10 (Python 3.11+, PySide6) для структурирования файлов в выбранной папке и поиска дубликатов.

## Возможности

- **Безопасность прежде всего**: сначала анализ, потом действие. Всегда показывается предпросмотр перед применением. Удаление — только в корзину (внутреннюю или системную через send2trash). Жёсткое удаление запрещено. Кнопка Undo отменяет последнее действие или весь batch.
- **Фоновые операции**: сканирование, хеширование и поиск дубликатов выполняются в отдельных потоках (QThread-воркеры), UI не блокируется, есть прогресс и отмена.
- **Кэш на SQLite**: повторный скан быстрее — если размер и mtime файла не изменились, хеш не пересчитывается. Есть кнопка «Очистить кэш».
- **Поиск дубликатов**: группировка по размеру → быстрый хеш (первые N байт) → полный хеш (SHA-256 по умолчанию). Режимы: exact, name_size, name_only, size_only.
- **Правила структурирования**: по расширению, дате, имени, размеру или пользовательские шаблоны (`{ext}`, `{year}`, `{month}`, `{day}`, `{stem}`). Приоритеты, fallback-папка Other.
- **Конфликты имён**: перезапись запрещена, создаются варианты `file (1).txt`, `file (2).txt`.
- **Исключения по умолчанию**: скрытые файлы, временные файлы, симлинки, папки `.git`, `node_modules`, `__pycache__`, `.venv`, `$RECYCLE.BIN`, `System Volume Information`, `AppData`, `Windows`.
- **Темы**: светлая и тёмная. Интерфейс на русском языке.
- **Устойчивость**: один проблемный файл не роняет приложение — ошибка фиксируется и сканирование продолжается.

## Данные приложения

Все данные хранятся в `%APPDATA%/FileOrganizer/`:

| Файл | Назначение |
|---|---|
| `settings.json` | Настройки |
| `cache.db` | SQLite-кэш хешей |
| `history.db` | История операций (undo) |
| `logs/app.log` | Лог |
| `trash/` | Внутренняя корзина |

## Установка и запуск

```bash
pip install -r requirements.txt
python file_organizer/run.py
```

## Тесты

Core-модули не зависят от PySide6 и покрыты pytest-тестами:

```bash
cd file_organizer
python -m pytest app/tests -q
```

## Структура проекта

```
file_organizer/
  app/
    core/        # чистый Python: models, config, cache, scanner, hasher,
                 # duplicates, rules, organizer, actions, history, logging
    ui/          # PySide6: main_window, workers, styles, widgets/, dialogs/
    tests/       # pytest-тесты core (без Qt)
    main.py      # точка входа
```

Архитектура: core-функции принимают явные зависимости (`settings`, `cache`, `progress_cb`, `log_cb`, `cancel_event`) — никаких глобальных переменных и синглтонов. Qt используется только в `app/ui/` и `main.py`.
